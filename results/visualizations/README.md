# Model visualizations

Generated by loading saved estimators and reports; no model fitting is performed.

Student-test top-1 and macro-F1 are against a proxy target: for each sampled GPS point, the nearest arc in its supplied reference route. They are not direct per-observation ground truth. The held-out route comparison plots use previously saved route-sequence evaluation results.

Cross-validation Macro F1 is not present in the saved experiments. Producing it properly requires fitting each model in multiple CV folds; this was skipped to honor the no-retraining request. Neither KNN nor Random Forest has epoch-based training histories, so loss curves are not applicable.

See `visualization_report.json` for generated outputs and exact aggregate student-test proxy metrics.
